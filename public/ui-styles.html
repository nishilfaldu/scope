Agent Passport Five UI directions · recommended Twin Desk

Twin Desk. Ship this. Humans mint and revoke on the left; agents get a first-class contract on the right (invoke URL, JSON, curl, actions). UX, DX, and AX stay in the same viewport.

Vellum. The product is a passport, so the UI is one. Strong recognition, weaker agent surface — pair with a copyable contract if you ship it.

Signal. Operator console. Best when the job is watching live actions and killing a session fast. Curl lives in a persistent terminal strip.

Stamp. Institutional trust. Numbered fields and a wax-seal revoke. Use if the buyer is security/compliance, not a developer.

Grid. Linear-like density. KPIs and a table scale past a handful of agents. Mint stays a rail, not a modal.
