# Scope brand mark

- `scope-mark.svg` is the editable vector master.
- `scope-mark-1024.png` is suitable for OAuth consent screens and app listings.
- `scope-mark-512.png` is a smaller square export.
- `scope-mark-120.png` is ready for OAuth consoles that request a 120 px app logo.

The artwork includes clear space inside the square canvas. Prefer the SVG when a service accepts vector uploads.

The mark uses Scope dark green (`#285C40`) with an off-white symbol (`#F7F9F7`). Keep the favicon and PNG exports in sync with the SVG master.
